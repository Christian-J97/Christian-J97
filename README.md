# Prototipagem e Modelagem de um Sistema Computacional

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido durante a graduação em **Análise e Desenvolvimento de Sistemas (ADS)** com o objetivo de aplicar conceitos de análise, modelagem e planejamento de sistemas computacionais.

A proposta foi compreender um problema e suas necessidades, organizar os requisitos e representar a solução de forma estruturada antes de sua implementação.

## 🛠️ Tecnologias e Metodologias Utilizadas

- **UML** — modelagem e representação da estrutura e funcionalidades do sistema.
- **BPMN** — representação dos processos e fluxos de negócio.
- **Modelo C4** — representação da arquitetura e dos componentes do sistema.
- **User Stories** — identificação e descrição das necessidades dos usuários.
- **Análise de Requisitos** — organização e definição das funcionalidades da solução.

## 📚 O que foi aprendido

Durante o desenvolvimento do projeto, foi possível compreender melhor como uma solução de software deve ser planejada antes da implementação.

Os principais aprendizados foram:

- Analisar problemas e identificar necessidades dos usuários.
- Estruturar e documentar requisitos.
- Representar processos utilizando BPMN.
- Utilizar UML para modelar sistemas.
- Compreender conceitos básicos de arquitetura de software através do modelo C4.
- Transformar necessidades e requisitos em uma solução tecnológica estruturada.

A experiência também reforçou a importância do **planejamento, organização, documentação e pensamento lógico** no desenvolvimento de software.
